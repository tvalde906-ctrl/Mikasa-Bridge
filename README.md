# Mikasa Bridge

**An AI-powered Minecraft companion project**

Mikasa Bridge is a fan-made project for Minecraft Java Edition 1.21.1, developed using Fabric.

The project brings an interactive character inspired by Mikasa Ackerman from *Attack on Titan* into Minecraft, combining artificial intelligence, environmental awareness, persistent memories and in-game interactions.

## How it works

Mikasa Bridge consists of two main components:

- **Mikasa NPC:** a Minecraft mod that implements the character, animations, interactions and game mechanics.
- **Mikasa Bridge:** a locally running Windows companion application that connects Minecraft to ChatGPT through Sign in with ChatGPT.

Eligible players authorize the application using their own ChatGPT accounts.

The project does not require users to provide conventional OpenAI API keys.

## Features

- AI-powered conversations
- Character personality and persistent memories
- Environmental perception
- Player-following and movement behaviors
- Minecraft interactions and actions
- Multilingual conversations and subtitles
- Optional voice synthesis through Fish Audio

Some features are still under development.
