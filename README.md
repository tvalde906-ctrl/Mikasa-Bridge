# Mikasa Bridge

**An AI-powered Minecraft companion project**

Mikasa Bridge is a fan-made project for Minecraft Java Edition 1.21.1, developed using Fabric.

The project brings an interactive character inspired by Mikasa Ackerman from *Attack on Titan* into Minecraft, combining artificial intelligence, environmental awareness, persistent memories, and in-game interactions.

## How It Works

Mikasa Bridge consists of two main components:

- **Mikasa NPC:** A Minecraft mod implementing the character, animations, interactions, and game mechanics.
- **Mikasa Bridge Windows:** A locally running companion application that connects Minecraft to ChatGPT through Sign in with ChatGPT.

Players authorize the companion application using their own eligible ChatGPT accounts. Conventional OpenAI API keys are not required.

## Features

- AI-powered conversations with contextual responses
- Character personality and persistent memories
- Environmental awareness and player recognition
- Following, navigation, guarding, and combat behaviors
- Custom character animations, dual blades, and ODM-inspired movement
- A naturally generated cabin and first encounter system
- Multilingual conversations and progressive subtitles
- Optional voice synthesis through Fish Audio

Some features remain experimental or under development.

## Requirements

- Minecraft Java Edition 1.21.1
- Fabric Loader
- Fabric API
- GeckoLib
- Java 21
- Windows for the companion application
- An eligible ChatGPT account and subscription

Optional voice features may require additional software or services.

## Installation

1. Install Minecraft Java Edition 1.21.1 with Fabric Loader.
2. Install Fabric API and GeckoLib for the compatible Minecraft version.
3. Place the Mikasa Bridge mod JAR in your Minecraft `mods` folder.
4. Download the Windows companion ZIP from GitHub Releases.
5. Extract the ZIP into a dedicated folder.
6. Launch the companion application using the included Windows launcher.
7. Follow the Sign in with ChatGPT authorization process.
8. Launch Minecraft and interact with Mikasa.

Do not upload your ChatGPT password or API keys to the project.
